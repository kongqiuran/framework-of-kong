# 骨架：论文精读与识别策略清单

> 在政经里，**"作者凭什么说是因果"这个问题，地位等同于理工科的数学**。
> 不会算微积分，电路课听不下去；不会问识别策略，论文读不出真假。
>
> 配套：`政治经济研究骨架.md` 的论文卡模板（`05-论文与证据/`）。

---

## 一、为什么政经必须练"识别"

理工科可以用实验裁决：接上示波器，波形对不对一目了然。
政经没有实验室——你无法随机让一半省份推迟 5 年搞土地财政，然后观察另一半。

于是所有实证研究的**重量全部压在"识别策略"上**。一篇文章的可信度不取决于结论多漂亮，取决于：

> **它凭什么说这个结果不是别的因素造成的？**

这个问题问不出口，你读的就不是研究，是意见。

## 二、三步速读法（按时间预算选）

### 第 1 步：5 分钟筛（值不值得读）

只读三处：**标题 + 摘要最后两句 + 结论第一段**。然后回答：

| 检查项 | 通过标准 |
|---|---|
| 问题是否明确 | 能一句话说出"作者在估计什么对什么的影响" |
| 有没有反事实 | 有对照组/断点/工具变量/合成控制，而不是"时间前后比较" |
| 数据是否可得 | 作者说明数据来源，或愿意公开 |
| 结论是否可证伪 | 存在能推翻它的观测 |

四条里过不到两条 → 放进 Inbox 当线索，不建论文卡。

### 第 2 步：30 分钟读（理解结论）

1. **Introduction 的最后三分之一**（作者在这里交代贡献与识别策略）
2. **识别策略那一节**（通常叫 Empirical Strategy / Identification）—— 这一段必须逐句读
3. **主回归表的第一列**（只看系数正负、显著性、样本量）
4. **Robustness 的第一小节**（看作者自己最担心的质疑是什么）

产出一句你能复述的话：**"作者用 ___ 作为识别来源，控制了 ___，结论是 ___。"**

### 第 3 步：2 小时精读（能挑刺）

- 数据描述统计：样本期、覆盖范围、缺失处理、关键变量的构造方式
- 平行趋势图 / 第一阶段 F 值 / McCrary 检验图 / 事前拟合图（看方法的"体检报告"）
- 标准误：是否聚类？聚类到哪一层？聚类层级与处理层级是否匹配？
- 异质性分析：是预先设定的，还是数据挖掘出来的？
- 机制检验：是"能排除别的解释"，还是"找到一个符合故事的变量"？

**精读的产出不是"我懂了"，是"我能说出这篇文章最薄弱的三个位置"。**

## 三、识别策略自检表（本文件的核心）

> 用法：读论文时先定位它属于哪一行，然后逐项对照"关键假设"和"常见失败信号"。

| 方法 | 一句话原理 | 关键假设（作者必须守住的） | 常见的失败信号（一眼看穿） |
|---|---|---|---|
| **RCT 随机实验** | 随机分组 → 两组可比 | 随机化成功；失访无差异；无溢出（SUTVA） | 样本小、失访率高且两组不同、大量子组结果里只有少数显著 |
| **DID 双重差分** | 处理组前后差 − 对照组前后差 | **平行趋势**；无预期效应；处理时点外生 | 事件研究图处理前就有趋势；改换处理年份/对照组结论就变 |
| **交错处理 DID** | 多期先后实施的处理 | 传统双向固定效应（TWFE）在**交错处理**下会给出负权重、估计值可能符号都错 | 用了 TWFE 却只做交错处理，且不引用 Callaway & Sant'Anna / Sun & Abraham / Goodman-Bacon 等修正方法 —— **这是当前最常见的硬伤** |
| **IV 工具变量** | 用外生变动分离内生部分 | 相关性（第一阶段要强）+ **排除性约束**（工具只能通过内生变量影响结果） | 不报第一阶段 F 值；弱工具（经验上 F<10 要警惕）；排除性约束只能靠"讲道理"却讲得很勉强 |
| **RDD 断点回归** | 阈值附近近似随机 | 断点两侧可比；运行变量**不可被操纵**；带宽不是挑出来的 | 断点处有异常堆叠（McCrary 检验）；换带宽就换结论；只报最漂亮的带宽 |
| **合成控制** | 用未处理单位的加权组合造反事实 | 事前拟合好；无溢出效应 | 事前拟合差；权重几乎全压在 1–2 个单位上；只报一个处理单位 |
| **事件研究** | 事件窗口内的异常变化 | 无混淆事件；窗口期正常 | 窗口开得太宽把别的事件也网进来；正常期本身波动很大 |
| **匹配（PSM 等）** | 用可观测特征配对 | **无未观测混淆**（这是很强且通常不成立的假设） | 只匹配了可观测变量就说因果；匹配后仍有系统性差异 |
| **结构模型** | 理论 + 参数 → 反事实模拟 | 模型设定正确；参数可识别 | 参数靠"校准"而非估计；结论对设定极度敏感 |
| **案例 / 过程追踪** | 案例内追踪因果机制 | 已排除竞争性解释 | 只找支持证据（确认偏误）；没有竞争假设；把"顺序"当"因果" |

### 关于"交错处理 DID"的额外说明

这是近十年计量经济学最大的一次"翻案"：**大量已发表论文使用的 TWFE 估计量在交错处理下是加权平均，权重可能为负**，导致估计值偏误甚至符号相反。
修正方法（Callaway–Sant'Anna、Sun–Abraham、de Chaisemartin–D'Haultfœuille、Borusyak 等）已成为新标准。
**读 2021 年之后的 DID 论文，如果作者完全没提这件事，要打问号。**

> ⏸ **待核验（不写死）**：以上具体文献年份与作者名是本清单的通行共识表述，
> 请在你第一次真正用到时，用 OpenAlex/Crossref 查出准确出处并在对应论文卡里留 DOI——**不要引用本清单作为文献来源**。

## 四、伪因果陷阱（写"机制卡"时逐条自查）

| # | 陷阱 | 症状 | 怎么破 |
|---|---|---|---|
| 1 | 遗漏变量 | A 与 B 同涨，其实是 C 驱动 | 找识别策略；问"还有什么同时影响两者" |
| 2 | 反向因果 | 以为是"监管→行为"，其实是"行为→监管" | 用时间先后 + 工具变量 |
| 3 | 自选择 | 参与者本来就与不参与者不同 | 找外生变动（政策门槛、抽签） |
| 4 | 幸存者偏差 | 只看活下来的样本 | 找完整的样本框（含失败者） |
| 5 | 均值回归 | 极端值自然回落被当成"干预有效" | 设置对照组 |
| 6 | 共同冲击 | 同期全国性变化被当成政策效果 | 找更细的对照组（未受政策影响的地区/行业） |
| 7 | 度量误差 | 关键变量有噪声 → 系数被系统性低估 | 找多套数据交叉验证；看作者的变量构造 |
| 8 | 多重比较 | 试了 20 个规格，报一个显著的 | 看有无预注册/多重检验校正 |
| 9 | 生态谬误 | 用全国数据推个体行为 | 明确分析单位，别跨层推理 |
| 10 | 口径断裂 | 口径某年改了，时间序列突然跳变被当成"趋势" | 查数据卡里的"口径变更史" |
| 11 | 发表偏倚 | 文献里一致有效，现实里无效 | 找未发表/复制研究；看 meta 分析 |
| 12 | 叙事谬误 | 事后编一个自洽故事 | 事前写判断卡，事后不许改 |

## 五、论文卡的填写纪律

模板见 `政治经济研究骨架.md` §3.4。三条硬规矩：

1. **`ref` 字段必须写 DOI 或可打开链接**，不许只写"某某论文"。
2. **识别策略栏不许留空**。哪怕是纯理论文章，也要写"这是理论/综述，没有识别策略"。
3. **"我信几分"必须写**，并说明是信**结论**、信**机制**、还是只信**数据**。

## 六、复现要求（差分优先）

你在量化项目里已经确立的原则：**第一版的目标不是"对"，是"差异清单"**。论文也一样。

### 三级复现标准

| 级别 | 做什么 | 证据 |
|---|---|---|
| R1 跑通 | 用作者公开的数据与代码跑出同样的表 | 环境记录 + 复现日志 |
| R2 复算 | 用**自己的脚本**（Python/statsmodels/linearmodels）复算核心系数 | 与我方实现对账，差异逐条归因 |
| R3 边界扫 | 换样本期/换带宽/换对照组/换聚类层级，看结论稳不稳 | **差异清单 + 归因表** |

### 差异归因（不许"大致对上就算过"）

| 归因类别 | 处理 |
|---|---|
| 我错 | 改我的代码，记录错在哪 |
| 他错 | 记录，并注明"作者结论依赖此处" |
| 口径/设定不同 | 明确写清双方口径，报告两种结果 |
| 数据源不同 | 记录数据商与版本（这是最常见的差异来源） |

**资源**：AEJ: Applied、AER、QJE 等要求作者公开复现包；
`larsvilhuber/aej-applied-replications-public` 是对经济学可复现性的系统研究，可用来判断"这个领域的复现率有多高"。

## 七、中文文献 vs 英文文献（读法不同）

| 维度 | 中文期刊 | 英文期刊 |
|---|---|---|
| 结构 | 常见"问题—现状—对策"三段式 | 强调 identification + contribution |
| 识别策略 | 相对宽松，DID/IV 用得多但敏感性检验较少 | 要求极严，稳健性与机制检验是标配 |
| 价值 | **快速建立问题意识、政策语境、制度细节** | **判断因果证据的强度** |
| 风险 | 引用链空转（A 引 B 引 C，没人读原文）；口径常不统一 | 与中国制度细节脱节；结论未必适用中国 |
| 用法 | 用来**提问题、找制度事实** | 用来**判证据强度** |

**推荐组合**：中文文献建"问题与制度地图" → 英文文献定"因果证据等级" → 两边冲突时回到 L1 原始数据自己看。

### 可核验的中文期刊入口

- **国家哲学社会科学文献中心**（`ncpssd.org`，免费检索）
- **CNKI**（`cnki.net`，检索免费、下载需权限）
- 期刊导航与影响因子以这两个平台为准，**不要依赖任何清单（包括本清单）作为权威判断**

### 一个可复用的发现：期刊技能包

GitHub 仓库 `brycewang-stanford/Awesome-Journal-Skills`（1.1k★，2026-09-17 实测）收录了数百个期刊的读写技能包目录（**实测 510 个目录项；去掉 `-Skills` 后缀后唯一名称 413 个，再减 3 个点目录 ⇒ 约 410 个期刊名**；初版误写为“510 个期刊”，已更正），其目录名是**期刊英文名**，其中包含多个中文刊的英文名形式（实测目录名，含：`Economic-Research-Journal`、`Journal-of-Management-World`、`Journal-of-Financial-Research`、`Journal-of-World-Economy`、`China-Economic-Quarterly`、`China-Industrial-Economics`、`China-Rural-Economy`、`Journal-of-Financial-and-Quantitative-Analysis`、`Social-Sciences-in-China`、`Sociological-Studies`、`Finance-and-Trade-Economics`、`Chinese-Public-Administration` 等）。

> ⚠️ **状态：`SINGLE-SOURCE` / 未逐个核实**。
> 我只读了目录列表，**没有打开每个目录核对内容**，因此"英文目录名 ↔ 中文刊名"的对应关系**待核实**。
> 核实方法：打开对应目录读其 `SKILL.md`，确认目标期刊。核实后把结论写进本文件并升级状态。
> 另注意 `Journal of Financial Research` 同时是某英文刊的名字，**存在同名歧义**——这正是不能凭印象对应的原因。

## 八、工具链

| 环节 | 工具 | 说明 |
|---|---|---|
| 检索 | **OpenAlex API**（首选）/ Crossref / Semantic Scholar / arXiv | 全部免登录，可脚本化（实测可达，见 `信源分级与信息流清单.md`） |
| 中文检索 | ncpssd（免费）→ CNKI（权限） | — |
| 管理 | **Zotero** | 与 Obsidian 联动；每条文献必须有 DOI |
| 笔记 | Obsidian | 论文卡命名：`作者-年份-关键词.md`，frontmatter 带 `ref: doi:...` |
| 复算 | Python（statsmodels / linearmodels / pyfixest）或 Stata | 本项目以 Python 为主 |
| AI 辅助 | 见 `AI工作流骨架/`；经济学专用工具可参考 `hanlulong/awesome-ai-for-economists` | ⚠️ AI 给出的文献引用**必须查 DOI 核实**，这是最容易出错的地方 |

### AI 辅助读论文的红线

1. **AI 说的文献、作者、年份、结论，一律当作 `UNVERIFIED`**，用 OpenAlex/Crossref 核验后才能写进卡片。
2. **识别策略的自检不能外包给 AI**——它倾向于顺着作者的叙述讲，而不是挑刺。
3. AI 可以做的：翻译、术语解释、把公式拆成步骤、帮我写复算脚本。
