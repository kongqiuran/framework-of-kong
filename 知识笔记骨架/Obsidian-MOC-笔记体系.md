# 骨架：Obsidian + MOC 笔记体系

> 适用于：理工科课程复习、知识体系搭建、从"学完"到"贯通"。
> 
> 融合了本地 Obsidian 实践与 GitHub 上 Zettelkasten 社区的最佳实践。

---

## 核心理念

**不要按教材章节记笔记，要按"认知层次"组织知识。**

教材是按"教学顺序"排列的，但你的大脑需要的是"因果网络"。

### 来自 GitHub 社区的洞察

> "Zettelkasten 不是笔记系统，而是**思考的外骨骼**。"  
> —— 来自 `GravityPHY/obsidian-zettelkasten`

> "每张卡片只记录一个想法，但卡片之间的链接会产生新的想法。"  
> —— Niklas Luhmann（Zettelkasten 发明者），被 GitHub 笔记社区广泛引用

- 要点

## MOC（Map of Content）的作用

MOC 不是目录，而是**"认知地图"**。

- 每张 MOC 说明这个层次的核心逻辑
- 用表格展示"向下一层的跳跃"
- 列出贯通实验（用物理解释电路现象）

### 来自 GitHub 社区的 MOC 实践

在 `zsc.github.io/fast_learning_tutorial` 中提到的知识管理原则：
- **支持快速检索**：用 Obsidian 的全局搜索 + 标签
- **深度链接**：不是简单的超链接，而是"这个概念是另一个概念的前提"
- **渐进式理解**：从摘录 → 总结 → 贯通 → 教学

---

## 双向链接约定

- `[[概念名]]` 表示指向另一张笔记
- 每张新卡片至少链接到一张已有卡片
- 定期用 Obsidian Graph View 检查"孤岛卡片"

### Zettelkasten 核心原则（GitHub 社区版）

来自 `GravityPHY/obsidian-zettelkasten`：

1. **原子性**：每张卡片只记一个想法/概念
2. **用自己的话写**：不是复制粘贴，而是理解后重新表达
3. **建立连接**：每张新卡片至少链接到一张已有卡片
4. **渐进式总结**：
   - 第一层：原文摘录（快速捕获）
   - 第二层：加粗重点（初步筛选）
   - 第三层：用自己的话总结（深度处理）
   - 第四层：与已有知识建立联系（网络构建）
5. **定期漫游**：用 Graph View 随机浏览，发现意想不到的关联

## 配套工具链

| 工具 | 用途 | 替代方案 |
|-----|------|---------|

- **Graph View**：可视化知识网络
- **Tag Wrangler**：标签管理
- **Templater**：笔记模板自动化
- **Dataview**：笔记数据库查询
- **Git**：直接在 Obsidian 内提交

## 使用流程

1. **新建项目**：复制本骨架，改目录名
2. **填充骨架**：把课程/教材的章节映射到四层结构
3. **日常学习**：
   - 有想法 → 99-Inbox
   - 深度思考 → 整理进对应卡片，建链接
   - 仿真验证 → 05-仿真实验
4. **定期 Review**：
   - 每周：清理 Inbox
   - 每月：Review Graph View，补链接
   - 每学期：git commit 历史就是认知演化史

## 与 GitHub 学习的联动

### 把自己的笔记变成"个人版 awesome list"

1. 在笔记中记录学过的 awesome list 资源
2. 用自己的话评价每个资源（"这个适合入门"/"这个已经过时"）
3. 定期整理成 MOC，如 `[[微电子学习资源总览]]`
4. 最终形成你的"个人知识策展"

### 用 GitHub 反哺笔记

- 读到好的开源项目 → 在笔记中创建 `[[项目名]]` 卡片
- 跑通复现代码 → 把实验记录链接到对应概念卡片
- 发现知识缺口 → 在 awesome list 中标记，定向学习

| 项目规模 | 建议层数 | MOC 数量 | 卡片目标 |
|---------|---------|---------|---------|
| 单门课程 | 3-4 层 | 1 个总览 + 3 个分层 | 20-50 张 |

| 跨学科体系 | 5+ 层 | 多个领域总览 + 顶层跨域总览 | 200+ 张 |
