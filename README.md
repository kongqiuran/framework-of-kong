# 骨架库（Template Library）

> 这里存放的是**"如何组织一个项目/知识体系"的元模板**。
> 
> 不是具体知识，而是**知识的容器结构**、**工作的流程框架**、**协作的规范契约**、**开源社区的最佳实践**。
> 
> 每次开新项目、新学科、新任务时，先从这里选一个骨架，再填内容。

### 7. 量化交易骨架
用于量化交易项目（股票/期货/加密）。**重点不是"怎么赚钱"，而是"怎么防止自己骗自己"**。

| 骨架 | 来源 | 适用场景 |
|-----|------|---------|
| [[量化交易项目骨架]] | 股票交易项目实战沉淀 | 量化交易项目的目录结构、阶段门禁、证据账本 |
| [[数据与策略验证清单]] | 同上（含真实踩坑记录） | 数据门禁、防前视、策略验证、许可证检查的逐项清单 |

**核心理念**：量化最大的风险不是亏钱，而是**回测漂亮、实盘不同、且找不到原因**。因此这套骨架把"数据可信 → 回测可信 → 样本外可信"拆成带证据的门禁，用程序判据代替自觉。

### 8. 政治经济骨架
用于建立**广义政治经济**（政府与市场、制度与激励、财政货币、国际政治经济、经济史）的知识体系与判断体系。

| 骨架 | 来源 | 适用场景 |
|-----|------|---------|
| [[政治经济研究骨架]] | 本地 MOC 体系 + 量化骨架的门禁思想改造 + GitHub 对标 | 六类卡片（概念/数据/政策/论文/立场/**判断**）+ 证据状态词 + 时效复核 |
| [[信源分级与信息流清单]] | 2026-09-17 本机 curl 实测 + GitHub 调研 | L1–L5 信源分级、日/周/月/季/年信息流、不可达源的替代方案 |
| [[论文精读与识别策略清单]] | awesome-causal-inference / awesome-economics / awesome-ai-for-economists | 三步速读、10 类识别策略自检、12 条伪因果陷阱、复现的三级标准 |
| [[外部对标调研]] | 本文的调研记录（含 21 个信息单元的引用回扫） | 说明骨架的依据、差异归因、未完成项 |

**核心理念**：理工骨架管"**学会了没有**"，政经骨架管"**我是不是被说服了**"。
政经的结论**有保质期**、**分歧是结构而非噪声**、**数据是人生产的**，
所以卡片格式必须多三样：口径与版本、立场与对手、时效与证伪条件。

> ⚠️ 与其它骨架的一个关键差别：这套骨架的"信源清单"是**实测的**（哪些站点能连、哪些要替代），
> 连通性每季度复测一次；`外部对标调研` 中的**补丁史考古尚未完成**，已在文件里显式标注。

## 使用原则

1. **骨架不是圣旨**：根据项目规模裁剪，小项目不必走完全流程
2. **骨架要演化**：每次项目结束后，回来更新骨架（"这次哪里浪费了时间？"）
3. **骨架先于内容**：先搭结构，再填内容。不要反向操作。
4. **一次只用一个主骨架**：不要混用冲突的流程
5. **善用 GitHub 社区**：骨架库本身是动态的，定期去 GitHub 发现新的 best practices
