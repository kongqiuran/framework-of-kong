# 骨架库（Template Library）

> 这里存放的是**"如何组织一个项目/知识体系"的元模板**。
> 
> 不是具体知识，而是**知识的容器结构**、**工作的流程框架**、**协作的规范契约**、**开源社区的最佳实践**。
> 
> 每次开新项目、新学科、新任务时，先从这里选一个骨架，再填内容。

## 使用原则

1. **骨架不是圣旨**：根据项目规模裁剪，小项目不必走完全流程
2. **骨架要演化**：每次项目结束后，回来更新骨架（"这次哪里浪费了时间？"）
3. **骨架先于内容**：先搭结构，再填内容。不要反向操作。
4. **一次只用一个主骨架**：不要混用冲突的流程
5. **善用 GitHub 社区**：骨架库本身是动态的，定期去 GitHub 发现新的 best practices
